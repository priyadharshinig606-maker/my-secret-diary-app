# my-secret-diary-app
A secure personal diary Android application developed using Kotlin and Android Studio
## Features

- 🔐 Secure Password Login
- 🔑 Change Password
- ❓ Forgot Password and Password Reset
- 📝 Write Diary Entries
- 💾 Save Multiple Diary Entries
- 😊 Mood Selection
- 📅 Automatic Date and Time
- 📖 View All Saved Diaries
- 🗑️ Delete All Diary Entries

## Technologies Used

- Kotlin
- Android Studio
- XML
- SharedPreferences

## About the Project

My Secret Diary is a simple Android application that allows users to securely write and manage their personal diary entries. The application provides password protection and features for saving, viewing, and deleting diary entries.
